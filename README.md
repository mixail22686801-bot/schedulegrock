# Расписание — виджет уроков для Android

## Что умеет приложение

- **Виджет** на рабочем столе:
  - Текущий урок + оставшееся время
  - Следующий урок
  - Если перемена — показывает «Перемена» и время до следующего
  - Справа — список всех уроков текущего дня (текущий отмечен ▶)
  - Можно менять размер (тяните за угол)
  - Можно менять цвет фона

- **Настройки** (откройте приложение):
  - Вкладки по дням недели (Пн–Вс)
  - Для каждого дня своё расписание
  - Добавление / редактирование / удаление уроков
  - Кнопка «Цвет» — смена цвета виджета
  - Кнопка «Обновить» — принудительное обновление виджета

## Как собрать APK

### Способ 1 — Android Studio (рекомендуется)

1. Установите [Android Studio](https://developer.android.com/studio)
2. File → Open → выберите папку `ScheduleWidgetApp`
3. Дождитесь синхронизации Gradle
4. Build → Build Bundle(s) / APK(s) → Build APK(s)
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`

### Способ 2 — командная строка

```bash
cd ScheduleWidgetApp
# если нет gradle wrapper — в Android Studio сделайте File → Sync
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`

## Как пользоваться

1. Установите APK на телефон
2. Откройте приложение «Расписание»
3. На вкладках дней добавьте уроки (название + время начала/конца)
4. Долгое нажатие на рабочий стол → Виджеты → «Расписание уроков»
5. Поставьте виджет и при необходимости растяните его

Виджет обновляется автоматически каждые 10 минут + при открытии приложения + по кнопке обновления.
